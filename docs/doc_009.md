# Hỗ Trợ Kỹ Thuật và Tài Liệu API

VinTech cung cấp REST API v2.0 cho tất cả sản phẩm. Authentication sử dụng Bearer Token (JWT). Rate limit: 1.000 requests/phút cho gói Basic, 10.000 requests/phút cho gói Pro/Enterprise. SDK hỗ trợ: Python, Node.js, Java, Go. Tài liệu API tại docs.vintech.vn. Sandbox environment miễn phí tại sandbox.vintech.vn. Webhook hỗ trợ retry 3 lần với exponential backoff.
