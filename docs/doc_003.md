# Nền Tảng VinAI Platform

VinAI Platform là bộ công cụ AI/ML do VinTech phát triển, ra mắt năm 2021. Nền tảng hỗ trợ training model, deployment và monitoring tự động. Giá khởi điểm 3.000.000 VND/tháng cho gói Starter (10 model deployments). Gói Team có giá 8.000.000 VND/tháng (50 deployments). Hiện tích hợp với các framework phổ biến: PyTorch, TensorFlow, scikit-learn.
